## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/anihere7/CodSoft-Java-Internship.git
```

### 2. Open the project

Open the downloaded folder in **VS Code** or any Java-compatible IDE.

### 3. Select a task

Navigate to the required task folder:

```text
Task 1
Task 2
Task 3
Task 4
Task 5
```

### 4. Compile and run

Compile the Java file:

```bash
javac FileName.java
```

Then run it:

```bash
java FileName
```

> Replace `FileName` with the actual Java file name.
